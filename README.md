# Ingrid Lima · Portfólio

Portfólio de design e social media de Ingrid Lima (@briefing.ao.pixel).

Site estático em HTML, CSS e JavaScript, sem build. Para rodar localmente, abra o `index.html` no navegador.

## Publicação na Vercel

1. Em vercel.com, clique em **Add New → Project** e importe este repositório.
2. Framework Preset: **Other**. Não precisa de comando de build nem de pasta de saída.
3. Depois do deploy, em **Settings → Domains**, adicione o domínio próprio.
